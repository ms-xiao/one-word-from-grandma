One word, and nothing else: the single word a grandma would text about AI.
A judge model compares words two at a time and the funniest, most
grandma-like word wins.

**The word** (11 characters):

> Smartypants

Why this word: it is the warm, slightly baffled thing a grandma texts when
the machine in her grandchild's pocket knows the answer to everything —
affectionate, a little scolding, and unmistakably grandma. It is tied to AI
through the one thing AI brags about (being clever), it lands as a joke with
no caption, and it is a fresh pick, not the obvious "robot".

`main.ts` (Node 22, standard library only) prints the word and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the word exactly as submitted. The gate requires
1–30 characters, not only whitespace; this word is 11.

## Run it

```sh
node main.ts
```
